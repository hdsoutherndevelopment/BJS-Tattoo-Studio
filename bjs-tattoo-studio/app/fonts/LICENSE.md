# Bundled typefaces

All four families are licensed under the SIL Open Font License 1.1 and are
redistributed here as latin-subset `.woff2` files (via Fontsource) so the build
has no external font dependency.

- **Anton** — Vernon Adams, Cyreal, Kirill Tkachev — https://fonts.google.com/specimen/Anton
- **Barlow** / **Barlow Condensed** — Jeremy Tribby — https://fonts.google.com/specimen/Barlow
- **Instrument Serif** — Rodrigo Fuenzalida, Jordan Egstad — https://fonts.google.com/specimen/Instrument+Serif
